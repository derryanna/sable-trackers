# Sable Trackers

Scene-state tracking for SillyTavern 1.19.x, with Russian output by default and English available. A separate, inexpensive side model updates scene notes after character replies. Your main model receives a compact digest of the sections you choose. State is saved in chat metadata; replies and message extras are never rewritten. Group chats are not supported.

[По-русски](#ru)

## Install and set up

1. Copy this repository's URL from its repository page.
2. In SillyTavern, open **Extensions → Install extension**, paste the repository URL, and install. Reload SillyTavern.
3. Create a **chat-completion** connection profile for an inexpensive model in SillyTavern's Connection Manager.
4. Open the scene drawer (edge tab or the extensions wand menu). Three short hints walk you through the rest: the first lets you pick that profile right there, the second explains the mode chip, the third tells you to write to the character. Each has **Next** (the last says **Got it**) and **Don't show again**; the first successful run also ends them, and **Settings → Actions → Show the hints again** brings them back. Until a usable profile is selected, the drawer status shows **No model profile → set up**, which opens the settings on the Connection group (you can also select the profile in **Extensions → Sable Trackers**; text-completion profiles appear disabled).
5. Choose the output language. **Model reasoning** (default "low") keeps thinking models such as GLM, Gemini or Kimi from spending the whole output limit on reasoning; "as the model decides" sends nothing. Turn off any other tracker that writes tracking blocks into the reply.
6. Open a character chat and generate a reply, or press **Run now** to update from the latest character reply.

Open the scene drawer from the edge tab, the extensions wand menu, or the panel under the latest character reply. The gear opens settings. Settings groups fold and remember their open or closed state; a folded group lists what it holds on a muted line under its title (Appearance: “panel, cards, background, card colours, effects”). The drawer supports folding, reordering and pinning. The pen button on a card opens an editor for that section: fix a field, add or remove rows, then Save (the change is injected into the next reply) or Cancel. The card colour is set in the same editor: its last row, **Card colour**, applies immediately, without Save. Settings can hide the reply panel or edge tab. Every mode menu ends with a short legend: inject — the model sees it · show — only you · off — not updated. After editing the latest reply, its old state is no longer injected: the cards dim and the drawer status shows **State is stale** with **⟳ Recompute**, which re-runs the side model for the edited reply; the next character reply clears it too.

While an update is running, the status says “updating…” with a pulsing dot and a spinning ⟳ (the **Effects** level “off” stops every animation). Tapping ⟳ for the same reply keeps that update running; otherwise it updates all enabled sections regardless of period. Folding, pinning and appearance changes never interrupt an update.

NPC rows show **About to** first, with **Secret** and **Deep down** hidden behind a **Secret** tap until the next state update or chat change; neither hidden field enters the main prompt. Turn off **Sections → Secrets and truths behind a tap** to display both as plain fields.

## Sections and modes

| Section | Contents | Default mode / period |
| --- | --- | --- |
| World | Time, place, weather and user-character condition | inject / 1 |
| Offscreen | Last known activity of absent NPCs | show / 1 |
| Open Threads | Open questions and conflicts | inject / 1 |
| Story | Seeds, deadlines and scene/arc phases | inject / 1 |
| NPCs | Presence, mood, outfit, intentions and actions | inject / 1 |
| NPC Inner Chatter | Private NPC thoughts | show / 1 |
| Bonds | Relationship scales and changes | inject / 1 |
| New NPC Dossiers | Brief dossiers, added once per new NPC | show / 0 |
| Story Planner | Possible next beats and a reminder | show / 5 |
| Ban List | Repeated phrases to avoid | inject / 3 |

**inject** requests, displays and includes the section in the main prompt. **show** requests and displays it without injection. **off** skips requests and injection, retaining the previous value for later.

Periods count character replies and apply globally. Dossiers always check for new names; their default 0 denotes this special behavior. Other sections with period 0 update every reply. Tap the drawer's mode chip to choose a mode from its menu; its last row, **Every N replies** (0–99), sets the same global period as the Sections table (never a per-chat override). Settings also provide mode and period selectors. Enable **Mode changes apply to this chat only** to save subsequent mode changes as chat overrides. Existing overrides remain active until **Reset overrides for this chat** is pressed; this preserves the tracked state and global settings.

Tap a card header to fold or unfold it. Switched-off sections are hidden by default: **Hidden: N** reveals them so you can switch them back on, and **Hide** hides them again. Disable **Actions → Hide switched-off sections** to always show their dimmed cards. In **Sections**, use **▲ ▼** to reorder built-in and custom sections; dragging the drawer handle still works.

**Old Sable data.** When this chat has no tracked state and compatible legacy data exists, the drawer shows a banner above the cards, “This chat has old Sable data”, with **Import** and **Hide** (hidden for this chat only). Nothing is imported automatically; import reads legacy message data without changing it.

**Bond scales** (settings → Bond scales): untick any of the ten built-in scales you don't need (say, keep only one of reputation and respect), and add up to 6 of your own with **Add scale**: a key (lower-case Latin letters, digits and `_`, the JSON field name), a title shown on the bar, one sentence telling the side model what it measures (e.g. `jealousy toward toward`), and **High value = friction** for the warm bar tint. Any scale, built-in or custom, can be made signed with its **−100…+100** checkbox: negative then means the opposite feeling (trust → distrust), the bar grows left or right from a centre line and the number carries its sign; values already stored stay as they are when you flip it. The side model is told exactly which scales exist: the default bonds instruction is rebuilt from the enabled ones, while an instruction override in the Danger zone replaces the whole text. A switched-off scale disappears from the next update; switching it back on starts it fresh.

**Custom blocks** (settings → Custom blocks): **Add block** creates a block with a title, an icon (one emoji or a Font Awesome class such as `fa-magnifying-glass`), a shape (text, list or key: value), a list cap (1–20), a mode, a period and your instructions for the side model. Delete takes two taps.

**Appearance** (settings → Appearance) adjusts the drawer's glass opacity, blur, font size, phone width, accent colour, corner radius and title icons (outline or emoji). For light themes, pick a **Base colour**: borders, dividers and text switch to black or white automatically, whichever reads better on it. **Text colour** overrides the text only. **auto** returns either one to the default dark glass / theme text. Sliders preview live while dragging; **Restore default look** resets everything. **Card colours** gives each built-in or custom card its own bar, chip and border colour; **auto** returns it to the shared accent. The same swatch and **auto** are the last row of a card's editor in the drawer; person cards take the Characters colour.

The group has five parts. **Panel**: glass and colours. **Cards**: corner radius, card fill, borders, title font (theme, serif, monospace, rounded — rounded only where such a font is installed) and weight, the look of the "inject" chip (filled or outline), spacing (cozy or compact), icons and the accent bar. **Background**: choose a picture (it is shrunk to 1280 px and saved in the extension settings, so every device that shares them shows it; over 600 KB after shrinking is refused) or paste an http(s) link; **Dimming** and **Fit** (fill, whole picture, tile) tune it. **Theme**: presets Glass, Paper and Neon set colours and style but keep your background, font size, width and effects; **Save theme file** downloads `sable-theme.json` (the whole look, picture included) and **Load theme file** applies one.

**Effects** is a level you pick: **off** stops every animation and transition, **subtle** (the default) makes bars slide to their new values, fades in change badges, brightens the accent bar of a changed card for a moment and marks it with a dot after the title until you unfold it or the next update, and lets you tap a stat row with a note to read it. **full** unlocks a set of effects that are each off until you switch them on: glow (colour and intensity), shimmer (speed and colour), rain behind the cards (density, colour, angle), numbers that tick to their new value, bars that shade towards the warning tint as they drop and pulse under 20 %, a dice spin with a result flash and a crit glow, and a glow pulse instead of the plain accent flash on changed cards (the reply panel's bars pulse too). Everything is plain CSS and DOM: no canvas, no libraries, nothing runs while you type, and the system reduced-motion setting forces “off”. Presets leave the level and the effects alone; theme files carry them. The reply panel shows one compact line per enabled pack (`HP 40/100 · stamina 70/100`, bars included) at every level.

**History sparklines under bars** (Cards, on by default): once a bond scale or a pack stat with a maximum (built-in packs and custom `stats` blocks; counters without a maximum have none) has two or more stored values, a row of up to 12 small bars under it shows where it has been, one bar per character reply that updated it (a swipe or a refresh of the same reply replaces its bar, deleting messages drops theirs). The history lives in the chat's metadata, is plain DOM without animation, and is not sent to any model. A stat that leaves the block takes its line with it. Tap a bar to see «reply #N · HP 40» under the line and scroll the chat to that reply (when it is not loaded in the chat, the label says “(not loaded)”); tap the same bar again to hide the label. With the keyboard, ←/→ move the pick and Enter jumps.

## Packs

Packs bundle sections and side-model rules for a scene. They are off by default and switched per chat with 🎒 in the drawer header or the **Packs** settings group. Switching on does not start a request: generate the next reply or refresh. Switching off keeps the stored values. Scope offers **all / only me / everyone but me**; Combat defaults to all, Intimacy and Intimacy+ to everyone but you, leaving your character’s state, feelings and responses to you.

In the drawer an enabled pack is one **group**: a card-like container with the pack title, a drag handle, a fold chevron and a group mode chip, with the pack’s cards nested inside. Each nested card keeps its own mode chip, so you switch on only the cards you need; the group chip shows their common mode or **mixed** and sets every card of the pack at once. Drag the group handle (or press ↑/↓ on it) to move the whole pack among the other cards; a nested card moves only inside its pack. Switched-off cards hide inside the group and count in **Hidden: N**; a pack whose cards are all off hides until you reveal them.

- **Combat** tracks the fight, HP, stamina, wounds and estimated odds; unresolved attacks stay unresolved.
- **Intimacy (18+)** tracks position, pace, consent state, arousal (a labelled estimate in any scene, so flirting shows too), stamina, explicit counters and visible marks only when every participant is an established adult; otherwise its values are empty. Two playful cards come along, shown but not injected unless you switch them: **Achievements** (video-game style badges for explicit events) and **Commentator** (a tongue-in-cheek line in the voice of a sports commentator, a nature documentary, a tabloid or a dating show).
- **Intimacy+ (18+)** is a deeper, explicit companion pack under the same adult guard: climax build-up, penetration and release (only when the text states them), body zones, kinks and dislikes (only from shown enjoyment, shown discomfort or stated words, kept across scenes), notable experiences and the afterglow; Zones, Experience and Afterglow are shown but not injected by default. It works alone or on top of Intimacy.

Create user packs or make an editable copy of a built-in pack, and export/import them as `sable-pack.json`. On stats or key/value rows whose key ends in `%` (including custom blocks), 🎲 rolls d100 locally without a model request. The result appears inline next to the button and is appended to the main prompt as a one-shot `ROLL` line for the next action. When the next character reply arrives, the line is removed and the inline result dims; swiping that reply does not reuse the roll. The latest roll replaces the previous one and is stored per chat, independently of edits or refreshes. **Danger zone → Show prompt** also shows the main prompt injection. The extension rolls or decides nothing else; a roll does not establish a hit or damage.

**Groups** are folders for existing built-in and custom cards, with a shared fold and mode chip. Use **Group…** under a card to move it into a folder, remove it with **No group**, or create **New group…**. **Edit group** changes the title and icon; **Delete group** keeps the cards. **Settings → Sections → Suggested groups** creates World, People and Story, replacing existing folders. Folders are global: at most 12, with up to 20 cards each and titles up to 40 characters. Drag a card by its handle to sort it; pull it more than a finger's width out of its folder (or deep into another one) and a dashed **here** slot shows where it will land: in a folder (its header means the end, a folded folder stays folded), or between top-level blocks outside any folder. Packs and the People group dim and do not take cards; a full folder shows **full**. Escape, sliding off the left of the panel or dropping with no slot cancels. Every drop, folder delete and suggested layout shows an **Undo** pill for 5 seconds (in memory only).

**Drawer layout.** **Settings → Sections → Drawer layout** switches the drawer from *by topics* (the default) to *by people*: the Characters, Thoughts, Bonds and Dossiers cards give way to one **People** group with a card per character (fields and the secret, the thought, the bond bars and the dossier together; present characters first, a dossier with no matching character last). The group chip sets all four sections at once. It is only a view: what is stored, sent to the side model and injected stays the same. The pencil in a person card's header opens **Edit** and **Delete**. **Edit** turns the card into one form for that person: Character, Secret / Actually (not sent to the model), Thought, Bond (one number per active scale) and Dossier, with **+ Dossier**, **+ Bond**, **+ Thought** (and **+ Character** on a dossier-only card) for missing parts; if the side model changes the data while the form is open, a **Data changed** bar offers **Reload** or **Save anyway**. **Delete** removes the person from all four sections and their bond history at once, with an **Undo** pill for 5 seconds. **+ Person** at the bottom of the People group adds a character by name and opens their form. The side model may add a deleted character back while the chat text still mentions them.

## Danger zone

The **Danger zone** group in settings (closed by default) lets you override the side model's common rules and each built-in section's instructions, with a **Default** button per field and **Reset all instructions**. **Show prompt** builds exactly the next **Run now** request without sending it; **Copy** puts it on the clipboard. The **Request log** keeps the last five runs with the request, the raw response, status and timing, with copy buttons, **Download log** (`sable-log.json`) and **Clear**. The JSON schema and output format stay fixed. The log lives in memory only, survives chat switches and is lost on reload.

## Token and storage notes

The side model reads the previous enabled state, the last 4 messages by default, up to 6000 character-card characters, up to 4000 activated-lore characters, and a short persona. It does not read the whole chat or lorebook. The output limit defaults to 3000 tokens. Reduce message/card/lore limits, turn unused sections off, or increase periods to reduce side-model usage. `show` still costs side-model tokens.

Only `inject` sections enter the main prompt, at depth 2 by default, with a digest capped at about 6000 characters. **Injection role** (system by default) is the role of that block: if the state block starts showing up in replies, try "user". Drawer token counts are estimates based on characters, not billing totals. The saved-state ring defaults to the last 3 messages per chat, every swipe of each included; this controls retained history, not model context length.

## Troubleshooting

- **No profile:** create a Connection Manager profile and select it in Sable settings. Reopen the settings block if the list is outdated. A deleted selection is shown as missing.
- **Not chat-completion:** use a profile whose completion mode is chat-completion. Text-completion profiles cannot be selected.
- **Empty or invalid output:** check that the profile works, increase the output token limit if the response was cut off, then try **Run now**. A thinking model that returns nothing usually spent the limit on reasoning: keep **Model reasoning** at "low" or "minimal". The model should return a JSON object inside `<sable_state>` tags. Invalid sections retain their previous values; inspect the drawer status and browser console for errors.
- **Nothing updates:** check Enabled, the selected profile, section modes and periods, and that the chat has a character reply. Group chats are unsupported. After editing the latest reply, press **⟳ Recompute** in the drawer status. **No model profile → set up** in the status means no chat-completion profile is selected.

## Кратко по-русски

После правки последнего ответа его старое состояние больше не вставляется в промпт: карточки тускнеют, а в строке статуса панели появляется «Состояние устарело» с кнопкой «⟳ Пересчитать», которая заново запрашивает вспомогательную модель для исправленного ответа; следующий ответ персонажа тоже снимает отметку. Каждое меню режима заканчивается подсказкой: в промпт — модель это видит · показ — только тебе · выкл — не обновляется.

В панели включённый пак — это одна **группа**: карточка-контейнер с названием пака, ручкой перетаскивания, кнопкой сворачивания и общей плашкой режима, внутри которой лежат карточки пака. У каждой вложенной карточки своя плашка режима, так что можно включить только нужные; плашка группы показывает их общий режим или **смешано** и задаёт режим всем карточкам пака сразу. Ручка группы (или ↑/↓ на ней) двигает весь пак среди остальных карточек; вложенная карточка двигается только внутри своего пака. Выключенные карточки скрываются внутри группы и учитываются в **Скрыто: N**; пак, у которого выключены все карточки, скрыт, пока вы их не покажете.

Паки — наборы секций и правил для сцены, по умолчанию выключенные: включайте их для текущего чата через 🎒 в заголовке панели или группу «Паки» в настройках, затем обновите трекеры или дождитесь следующего ответа. «Бой» отслеживает ход боя, здоровье, силы, раны и шансы; «Интим (18+)» — положение, темп, согласие, возбуждение (осторожная оценка в любой сцене, флирт тоже виден), силы, явные счётчики и видимые следы, только если все участники заведомо взрослые, иначе значения пустые. Плюс две весёлые карточки, по умолчанию только показ без вставки в промпт: «Ачивки» (значки в духе игровых достижений за явные события) и «Комментатор» (ехидная реплика голосом спортивного комментатора, документалки о природе, таблоида или телешоу). «Интим+ (18+)» — второй, более глубокий и откровенный пак под той же проверкой взрослости: шкала оргазма, проникновение и финал (только если они прямо описаны), зоны тела, кинки и антикинки (только по явному удовольствию, явному дискомфорту или словам, сохраняются между сценами), опыт и состояние «после»; «Зоны», «Опыт» и «После» по умолчанию только показываются. Его можно включать отдельно или вместе с «Интимом». Охват: «все / только я / кроме меня»; по умолчанию «Бой» учитывает всех, а «Интим» и «Интим+» — всех кроме вашего персонажа, оставляя его состояние, чувства и реакции вам. Можно создавать свои паки, копировать встроенные и обмениваться файлами `sable-pack.json` через экспорт и импорт. Кнопка 🎲 у ключей с `%` в показателях и парах ключ/значение, включая свои блоки, бросает d100 локально, без запроса к модели: результат виден рядом с кнопкой и однократно добавляется строкой `ROLL` в промпт для следующего действия. После ответа персонажа строка исчезает из вставки, а результат тускнеет; свайп этого ответа не возвращает бросок. Последний бросок хранится отдельно для каждого чата до следующего и не меняется при правке или обновлении секций. Больше расширение ничего не разыгрывает и не решает, а бросок сам по себе не означает попадание или урон.

**Группы** — папки для существующих встроенных и своих карточек, с общим сворачиванием и плашкой режима. Меню **«В группу…»** под карточкой переносит её в папку, **«Без группы»** возвращает в общий список, **«Новая группа…»** создаёт папку. **«Редактировать группу»** меняет название и значок; **«Удалить группу»** сохраняет карточки. **Настройки → Секции → «Разложить по группам»** создаёт «Мир», «Люди» и «Сюжет» вместо существующих групп. Группы общие для всех чатов: до 12 папок, до 20 карточек в каждой, название до 40 символов. Карточку можно тянуть за ручку: внутри папки она просто сортируется, а если вытащить её из папки (или завести глубоко в другую), появится пунктирное место «сюда» — в папке (на заголовке — в конец, свёрнутая папка не раскрывается) или между блоками без группы. Паки и группа «Люди» тускнеют и карточки не принимают; у полной папки значок «полная». Escape, увод пальца левее панели или отпускание без места отменяют перенос. После переноса, удаления группы и «Разложить по группам» 5 секунд видна плашка «Вернуть» (только в памяти).

**Раскладка панели.** **Настройки → Секции → «Раскладка панели»** переключает панель с *по темам* (по умолчанию) на *по персонажам*: вместо карточек «Персонажи», «Мысли», «Отношения» и «Досье» появляется одна группа **«Люди»** с карточкой на каждого персонажа (поля и тайна, мысль, полоски отношений и досье вместе; сначала те, кто в сцене, досье без пары — в конце). Плашка группы задаёт режим всем четырём секциям сразу. Это только вид: что хранится, уходит вспомогательной модели и вставляется в промпт, не меняется. Карандаш в заголовке карточки персонажа открывает **«Редактировать»** и **«Удалить»**. **«Редактировать»** превращает карточку в одну форму: Персонаж, Тайна / На самом деле (не идёт в промпт), Мысль, Отношения (по числу на каждую включённую шкалу) и Досье; недостающее добавляют **«+ Досье»**, **«+ Отношения»**, **«+ Мысль»** (и **«+ Персонаж»** у карточки, где есть только досье). Если вспомогательная модель обновит данные, пока форма открыта, появится плашка **«Данные обновились»** с **«Перечитать»** и **«Сохранить всё равно»**. **«Удалить»** убирает персонажа сразу из всех четырёх секций вместе с историей отношений; 5 секунд можно нажать **«Вернуть»**. **«+ Человек»** внизу группы «Люди» добавляет персонажа по имени и открывает его форму. Вспомогательная модель может вернуть удалённого персонажа, пока текст чата его упоминает.

**Шкалы отношений** (настройки → «Шкалы отношений»): снимите галочки с ненужных встроенных шкал (например, оставьте одну из «Репутации» и «Уважения») и добавьте до 6 своих кнопкой «Добавить шкалу»: ключ (строчная латиница, цифры и `_`, имя поля в JSON), название на полоске, одно предложение для вспомогательной модели о том, что шкала измеряет (например, `jealousy toward toward`), и «Высокое значение = трение» для тёплого оттенка полоски. Любую шкалу, встроенную или свою, можно сделать знаковой галочкой «−100…+100»: отрицательное значение означает противоположное чувство (доверие → недоверие), полоска растёт от центра влево или вправо, а число показывается со знаком; уже сохранённые значения при переключении не меняются. Вспомогательной модели сообщается точный набор шкал: инструкция по умолчанию пересобирается из включённых, а своя инструкция в «Опасной зоне» заменяет её целиком. Выключенная шкала исчезает со следующего обновления; включённая снова начинается заново.

Sable Trackers хранит состояние сцены отдельно от сообщений. Недорогая вспомогательная модель обновляет трекеры, а основная получает только краткую выжимку выбранных разделов.

Установка: скопируйте URL этого репозитория, откройте **Extensions → Install extension**, вставьте URL и перезагрузите SillyTavern. Создайте в Connection Manager профиль **chat-completion** для недорогой модели и откройте панель: три короткие подсказки («Проверь соединение» с выбором профиля прямо в ней, «Выбери, что нравится», «Наслаждайся») ведут дальше, у каждой есть «Дальше» / «Понятно» и галочка «Больше не показывать»; первое успешное обновление тоже их убирает, а «Настройки → Действия → Показать подсказки снова» возвращает. Пока профиль не выбран, в статусе панели висит кнопка «Нет профиля модели → настроить», открывающая настройки на группе «Подключение» (профиль можно выбрать и в **Extensions → Sable Trackers**). Отключите другие трекеры, записывающие блоки в ответ. Русский язык выбран по умолчанию. «Размышления модели» (по умолчанию «мало») не дают думающим моделям вроде GLM, Gemini или Kimi потратить весь лимит ответа на размышления; «как у модели» ничего не отправляет. Группы настроек сворачиваются и запоминают своё открытое или закрытое состояние; у свёрнутой группы под названием приглушённой строкой перечислено содержимое («панель, карточки, фон, цвета карточек, эффекты»).

Режимы: **в промпт** — обновлять, показывать и передавать основной модели; **показ** — только обновлять и показывать; **выкл** — не запрашивать раздел, сохранив старое значение. Период задаётся в ответах персонажа: в таблице «Секции» или последней строкой меню плашки режима, «Раз в N ответов» (0–99), — это одна и та же общая настройка, не локальная для чата. Переключатель «только для этого чата» сохраняет локальные режимы, кнопка сброса возвращает общие. «Обновить сейчас» запускает обновление вручную. Если в чате есть совместимые данные старого Sable, а история трекера пуста, над карточками появляется плашка «В этом чате есть данные старого Sable» с кнопками «Импортировать» и «Скрыть» (скрывается только в этом чате); сам импорт никогда не запускается.

В строке NPC первым показано «Собирается», а «Тайна» и «На самом деле» открываются нажатием на «Тайна» до следующего обновления состояния или смены чата; оба скрытых поля не попадают в основной промпт. Отключите **Секции → Тайны и «на самом деле» за спойлером**, чтобы показывать их обычными полями.

Нажмите на плашку режима и выберите вариант в меню. Нажатие на заголовок карточки сворачивает или разворачивает её. Выключенные разделы по умолчанию скрыты: **Скрыто: N** временно показывает их для включения, **Скрыть** убирает снова. Настройка **Действия → Скрывать выключенные** отключает это скрытие. В таблице **Секции** кнопки **▲ ▼** меняют порядок встроенных и своих блоков; перетаскивание за ручку в панели тоже работает. Цвет карточки задаётся в её редакторе (карандаш «Редактировать»): последняя строка «Цвет карточки» применяется сразу, без «Сохранить».

Внешний вид (настройки → «Внешний вид»): «Панель» — стекло и цвета; «Эффекты» — уровень «выкл / мягко / полные»: «мягко» плавно двигает полоски и подсвечивает изменения, «полные» открывает набор эффектов (свечение, блик, дождь, бегущие числа, цвет полоски по значению, анимация кубика, вспышка свечения), каждый из которых включается отдельно, а системная настройка «меньше движения» выключает всё; «Карточки» — скругление, заливка, рамки, шрифт и жирность заголовков, кнопка «в промпт» (залитая или контур), плотность, значки и полоса слева; «Фон» — картинка с устройства (сжимается до 1280 px и хранится в настройках расширения, поэтому видна на всех устройствах; больше 600 КБ после сжатия не принимается) или ссылка http(s), затемнение и размещение; «Тема» — пресеты «Стекло», «Бумага», «Неон» (фон, размер шрифта, ширина и эффекты остаются), «Экспорт темы» в файл `sable-theme.json` вместе с картинкой и «Импорт темы». «Сбросить вид» возвращает всё по умолчанию. Тот же образец и «авто», что и в «Цветах карточек», есть последней строкой в редакторе карточки; карточки людей берут цвет «Персонажей».

«Мини-графики под полосками» («Карточки», включено по умолчанию): когда у шкалы отношений или у стата пака с максимумом (встроенные паки и свои блоки вида `stats`; у счётчиков без максимума графика нет) накопилось хотя бы два значения, под полоской появляется ряд до 12 маленьких столбиков — по одному на ответ персонажа, обновивший шкалу (свайп или повторное обновление того же ответа заменяет его столбик, удаление сообщений убирает их). История хранится в метаданных чата, рисуется обычным DOM без анимации и никуда не отправляется. Стат, пропавший из блока, уносит свою линию. Нажмите на столбик — под графиком появится «ответ #N · HP 40», а чат прокрутится к этому ответу (если он не загружен в чате, подпись добавит «(не загружено)»); повторное нажатие на тот же столбик прячет подпись. С клавиатуры: ←/→ двигают выбор, Enter переходит.

«Опасная зона» (в настройках, свёрнута по умолчанию): общие правила и инструкции каждой встроенной секции можно переписать, у каждого поля есть кнопка «По умолчанию», внизу — «Сбросить все инструкции». «Показать промпт» собирает в точности следующий запрос «Обновить сейчас», не отправляя его; «Копировать» кладёт его в буфер. «Журнал запросов» хранит последние пять запусков: запрос, сырой ответ, статус и время, с копированием, «Скачать журнал» (`sable-log.json`) и «Очистить». Схема JSON и формат ответа не меняются. Журнал живёт только в памяти, переживает смену чата и исчезает при перезагрузке.

«Роль вставки» (по умолчанию «система») — роль блока состояния в промпте: если блок состояния начал появляться в ответах, попробуйте «пользователь».

Если нет обновлений, проверьте профиль, режим chat-completion и включённые разделы. При пустом ответе проверьте модель, увеличьте лимит токенов и повторите обновление; думающая модель, которая ничего не вернула, обычно потратила лимит на размышления — держите «Размышления модели» на «мало» или «минимум». Групповые чаты не поддерживаются.
